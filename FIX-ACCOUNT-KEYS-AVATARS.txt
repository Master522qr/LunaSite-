LunaVisual — исправление аккаунтов, ключей и аватаров

1. Пользователи регистрируются только на сайте через Supabase Auth.
2. В лаунчере отдельная регистрация не требуется. Ключ, созданный на сайте, вводится в лаунчере.
3. Генерация ключей в профиле администратора проверяет только активную сессию сайта.
4. Для Glav-Luna/Bobretor10@gmail.com используется project-avatar.png.
5. Остальные аватары загружаются через mc-heads.net, при ошибке показывается локальный логотип.

ОБЯЗАТЕЛЬНО: снова выполните supabase_setup.sql в Supabase -> SQL Editor.
После обновления сайта один раз выйдите из аккаунта и войдите заново, чтобы обновить JWT-сессию.
