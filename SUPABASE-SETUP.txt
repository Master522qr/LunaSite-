Launcher integration:
- Website download path: public Storage bucket downloads / LunaVisual.exe
- Launcher should authenticate against the same Supabase project, then call RPC get_lunavisual_launcher_state().
- The returned state contains user_id, email, nickname, hwid, subscription_active, subscription_until, is_admin and maintenance.
- The launcher source/binary was not present in the provided website archive, so upload the actual LunaVisual.exe to the downloads bucket and implement the RPC call in the launcher source.
