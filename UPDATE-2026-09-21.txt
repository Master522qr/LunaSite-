LunaVisual — обновление сайта

1. Регистрация и вход выполняются только на сайте через Supabase Auth.
2. Лаунчер не требует отдельной регистрации для генерации ключей.
3. Активация ключа на сайте работает через RPC redeem_lunavisual_key.
4. Генерация ключей владельцем работает через RPC generate_lunavisual_keys.
5. Владелец: Bobretor10@gmail.com / Glav-Luna (проверка по email и is_admin).
6. В админ-панели есть база всех ключей, ID аккаунта использовавшего ключ, удаление одного ключа и массовое удаление использованных ключей.
7. Аватар владельца — логотип проекта. Для остальных сначала используется mc-heads, затем minotar, затем локальный логотип.
8. Кнопка "Купить" в меню ведёт на https://funpay.com/users/17507792/
9. Кнопки покупки тарифов открывают выбор: Telegram или FunPay.
10. Почта поддержки: techbitsupport@gmail.com
11. Версия Minecraft/Fabric на сайте: 1.21.11.

ВАЖНО: после загрузки файлов на GitHub Pages выполните актуальный supabase_setup.sql в Supabase SQL Editor. Без RPC-функций генерация/активация ключей работать не будет.
